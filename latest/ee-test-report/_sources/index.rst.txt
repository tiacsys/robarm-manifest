EE Test Report
==============

This document shows the results of the EE test cases of the EE Test Specification.

.. note::

   No results: there is no EE test case yet (``ee-test-spec``).

What will go here
-----------------

* for each EE test case, its latest result (``TR`` needs, ``result of`` the ``EE-TC``), recorded
  from ``main`` or a baseline commit (D60) on the ``evidence`` branch of robarm-integration;
* the coverage of the EE requirements by passed tests.

The ERC and DRC results of each board are not test results; they are in the board documents.
