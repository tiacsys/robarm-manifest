Canary

The canary test case belongs to the system configuration canary (SYS-CFG-0001), a small trace chain that tests the tools (plan task 5.3).

The test case need is generated from the comment above the ZTEST in tests/canary/src/main.c (its Test case:, Verifies and Configs: sentences) by curatrix gen code-needs robarm-sw into generated/code-needs.json, and imported here. For a few input values, canary_update() returns the same value, and the call takes at most 1 ms.

SW Test Case: The canary output follows a changed input within 1 ms SW-TC-0001
status: valid
source_file: tests/canary/src/main.c
configs: SYS-CFG-0001
verifies: SW-REQ-0001

ZTEST test_output_follows_input in suite canary (tests/canary/src/main.c). Twister reports it as robarm.canary.canary.output_follows_input.
