Project Decisions

Decisions about the robot arm project are recorded on this page as prj-dec needs, with IDs PRJ-DEC-nnnn from the ledger robarm-manifest/ids.yaml. Decisions about the XDMOD method itself are framework decisions (xd-adr) in the XDMOD manual. A project decision that applies or tailors a framework decision follows it.

The split: a decision is a project decision when it is only true for the robot arm: its targets and scope, its hardware, its GitHub org, repos and settings, its licence, and its pinned SDK. Everything that would hold for any other project that uses XDMOD (method, trace model, IDs, checks, tools, repo pattern, workflow, agent rules) is a framework decision. legacy_id is the decision’s number in the planning log.

Project Decision: Phase 4 merge rights PRJ-DEC-0016
status: valid
legacy_id: D140
date: 2026-11-15
decision_status: accepted
follows: XD-ADR-0044, XD-ADR-0051

Phase 4 merge rights: initial skeletons go straight to main of the new repos before the ruleset is switched on. After that, all Phase 4 work goes through PRs, and the coordinator agent may merge them in xdmod and robarm-* once CI is green and the agent review has no blocking findings. The owner gets a summary of each merge. This is a Phase 4 exception to XD-ADR-0044 and XD-ADR-0051.
Project Decision: Rulesets per repo PRJ-DEC-0017
status: valid
legacy_id: D141
date: 2026-11-15
decision_status: accepted
refines: PRJ-DEC-0012
follows: XD-ADR-0043, XD-ADR-0122

Rulesets are per repo, not per org. Org rulesets need the GitHub Team plan. Each of the 7 repos has the same xdmod-main ruleset on its default branch: PR required (0 approvals, rebase only), linear history, no force push, no deletion. The admin role may bypass only through a PR (no direct pushes to main). Required status checks and “branches up to date” (XD-ADR-0122) are added in task 4.4, once each repo’s CI check names exist. Refines Phase 4 GitHub action list (PRJ-DEC-0012).

Required checks (task 4.4): in each repo’s xdmod-main ruleset, required status checks with “branches up to date” (XD-ADR-0122) from the GitHub Actions app: xdmod tests + check / check; robarm-syseng, -ee, -me, -sw, -integration check / check; robarm-manifest full-set (check run on normal PRs, commit status on bump PRs).
