EE Requirements and Design

This document holds the electrical requirements of the robot arm and the electrical design that meets them.

Note

This is a skeleton. The content comes in Phase 6.

What will go here

  • the EE requirements, written as EARS sentences, each refining a system requirement;

  • the design of each PCBA: schematic sheets, bill of materials, and the nets compared with the system interfaces (all read from the KiCad files);

  • the wiring of each prototype setup (NUCLEO-G474RE board, breakout boards, servos and potentiometers);

  • the EE test cases and their results.

In iteration 1 this is one document. It will be split into a requirements document, one document per PCBA, one per prototype setup, and test documents once that content exists.
