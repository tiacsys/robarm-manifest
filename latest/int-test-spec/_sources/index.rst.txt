System and Integration Test Specification
=========================================

This document lists the system test cases and the integration test cases of the robot arm, and
the hardware-in-the-loop (HIL) setups they run on.

.. note::

   This is a skeleton. The content comes in Phase 5.

What will go here
-----------------

* the system test cases: each one verifies system requirements from the Stakeholder and System
  Requirements Specification;
* the integration test cases: each one verifies system interfaces from the System Architecture;
* the HIL setups: the hardware, the wiring (from the EE design) and the configuration of the
  system each setup represents.
