Firmware: robarm_app (fw-robarm-app)

This document describes one firmware image: the Zephyr application app/ of robarm-sw, the deliverable that goes onto the controller board. It is the SW counterpart of a board document (pcba-<board>) or an assembly document (asm-<assembly>) (tiacsys/xdmod#69 decision Q8). Requirements, architecture and tests of the software are in sw-req, sw-arch, sw-test-spec and sw-test-report.

Note

A skeleton with what robarm-sw has today. Image version, size and memory map are placeholders until the firmware has a version file and the build output is part of the document.

not set yet: the application has no VERSION file, so the image carries Zephyr’s default version

not linked yet (no SYS-CFG on the image)
