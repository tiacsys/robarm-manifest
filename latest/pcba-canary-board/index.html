Canary Board (pcba-canary-board)

This document describes the board canary-board: the KiCad project pcba/canary-board/canary-board.kicad_pro and the board def of the EE model it implements. It was made by curatrix new pcba; every board document has the same sections (XD-ADR-0129). The tables come from the KiCad files in plain Python; renderings, schematic and ERC/DRC findings come from the local curatrix cam output of the current commit and are not part of CI builds.

Overview

  • Board: EE-PCBA-0001

  • KiCad project: pcba/canary-board/canary-board.kicad_pro

  • Version, ERC/DRC: Made locally with KiCad (curatrix cam) for the current commit; not part of this build.

  • Variants: default, alt
