Canary

The canary module belongs to the system configuration canary (SYS-CFG-0001), a small trace chain that tests the tools (plan task 5.3). It is not part of the robot arm firmware.

SW Architecture Element: Canary module SW-ARCH-0001
status: valid
configs: SYS-CFG-0001
refined by: SW-DD-0001
satisfies: SW-REQ-0001
realizes: SYS-EL-0001

The software part of the canary unit: one function in app/src/canary.c. It is not linked into the robot arm firmware; only the test tests/canary builds it.
SW Detailed Design Element: canary_update() SW-DD-0001
status: valid
configs: SYS-CFG-0001
refines: SW-ARCH-0001
satisfies: SW-REQ-0001
implemented by: SW-IMPL-0001

int32_t canary_update(int32_t input) returns the new output for an input value. The output equals the input, computed at once, with no waiting and no state.

The code unit that implements the design element is generated from the @xdid Doxygen block in app/src/canary.h (curatrix gen code-needs robarm-sw) and imported here:

Code Unit: canary_update() SW-IMPL-0001
status: valid

configs: SYS-CFG-0001
implements: SW-DD-0001

Return the new canary output for an input value.
