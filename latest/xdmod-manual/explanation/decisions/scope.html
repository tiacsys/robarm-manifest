Scope and iterations

What is in iteration 1 and what moved to iteration 2.

Framework Decision: CAM data from CAD data is a framework task XD-ADR-0018
status: valid
legacy_id: D23
date: 2026-11-14
decision_status: revised
revised by: XD-ADR-0037

Creating and storing CAM data from CAD data (ME and EE) is a task of the framework. Moved to iteration 2 by Scope moved to iteration 2 (XD-ADR-0037).
Framework Decision: All design outputs go into a bundle XD-ADR-0019
status: valid
legacy_id: D24
date: 2026-11-14
decision_status: revised
refined by: XD-ADR-0034
revised by: XD-ADR-0037

All design outputs, including the pre-built firmware, go into a bundle. The user will share a bundling tool later. Terms fixed by Terms: baseline and bundle (XD-ADR-0034); moved to iteration 2 by Scope moved to iteration 2 (XD-ADR-0037).
Framework Decision: ME CAM output is 3MF and STL plus print settings XD-ADR-0024
status: valid
legacy_id: D30
date: 2026-11-14
decision_status: accepted

ME CAM output is 3MF (and STL) plus a print-settings profile. No G-code.
