Work as an agent

Use this guide if you are an AI agent, or if you brief one. Agents do the same work with the same tools as people (Agents are first-class (XD-ADR-0003)). The differences are listed here.

Before you start

  1. Read the workspace CLAUDE.md (copied from xdmod/launch/CLAUDE.md, Agent material in each repo... (XD-ADR-0062)) and the claude/CLAUDE.md of each repo you change.

  2. Get a brief: goal, binding decisions, files to read, output paths, and what you must not do.

  3. Work in your own worktree set (Parallel agents work in git... (XD-ADR-0114)): curatrix work start <branch> <repos...>. One agent per branch per repo.

merge PRs, push to main, force-push to other people’s branches

Rules while working

  • Run every command from the workspace root (All commands run from the w... (XD-ADR-0060)). Run tools that curatrix has no subcommand for through curatrix run -- <cmd> (Every tool runs under limits (XD-RULE-0044)).

  • Write placeholder IDs and run curatrix ids fix; never invent numbers (No placeholders on main (XD-RULE-0017)).

  • Put build output only under build/<area>/ (Build output only under build/ (XD-RULE-0040)).

  • Every commit ends with Co-Authored-By: <agent> <noreply@anthropic.com> (Agents work under the user'... (XD-ADR-0044), Agent commits carry a trailer (XD-RULE-0042)). Everything posted on GitHub ends with the provenance trailer.

  • Run curatrix check <repo> --stage local for every repo you touched before you push.

  • Every PR gets a review by another agent before the owner’s review (Every PR gets an agent review (XD-ADR-0115)).

Skills and checklists

The bootstrap links skills and commands from xdmod/claude/ and each active repo’s claude/ folder into <workspace>/.claude/ (The bootstrap assembles .cl... (XD-ADR-0103)).

Skills and commands are linked with the prefix of their repo: xd- for xdmod. The review command is /xd-review-pr <repo> <PR>; its checklists are in xdmod/claude/checklists/. The first skills cover stakeholders and needs, EARS requirements and IDs; the KiCad and FreeCAD skills are completed after their spikes. The rules for changing xdmod itself are in xdmod/claude/CLAUDE.md.
