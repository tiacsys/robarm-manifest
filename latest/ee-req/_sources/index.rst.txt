EE Requirements Specification
=============================

This document holds the requirements on the electrical design of the robot arm: the boards, the
harnesses and the prototype wiring. The design that meets them is in the EE Design document
(``ee-design``), the test cases that verify them in the EE Test Specification (``ee-test-spec``).

.. note::

   No EE requirement yet. ``ee-design`` held "Requirements and Design" until the V-model split
   (tiacsys/xdmod#69 decision Q8); it had no EE requirement to move. The ledger has no ``EE-REQ``
   ID yet.

What will go here
-----------------

* the EE requirements (``.. ee-req::``), written as EARS sentences with value fields where they have
  a number (CK-E2, CK-E3);
* for each EE requirement, the system requirement or interface it refines (from the documents of
  robarm-syseng, which this build includes).
